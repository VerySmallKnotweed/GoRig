# Сбор отчётов

Сборка на Windows из корня репозитория (нужна версия Go не ниже указанной в go.mod):

```bat
go build -o GoRigCollector.exe ./cmd/gorig-collector
```

Скопируйте `GoRigCollector.exe` на флешку и запускайте на каждом компьютере.
Без параметров отчёт сохраняется **рядом с exe**, а не в текущем каталоге:
`gorig-report-<scan_id>.json`. У каждого запуска новый идентификатор; существующий
файл с таким именем не перезаписывается. На флешке должно быть разрешено создание
файлов. Сообщение о результате содержит полный путь. Если запускать программу
двойным щелчком, окно может закрыться сразу; для чтения сообщений можно запускать
её из командной строки.

Необязательный параметр по-прежнему задаёт конкретный путь к файлу:

```bat
GoRigCollector.exe D:\reports\example.json
```

**Внимание:** при явном указании пути существующий файл по этому пути заменяется.
Каталог должен существовать. В одном отчёте содержатся сведения одного запуска;
отчёты можно просматривать и импортировать в GoRig Base с ручным выбором
карточки компьютера.

## Что собирается

Коллектор запрашивает через WMI общую физическую память,
доступную Windows, сведения и дату установки Windows, число ядер процессора,
размер и интерфейс физических дисков, BIOS и физические сетевые адаптеры с
MAC-адресами. Отдельно остаются модули памяти и другие ранее собиравшиеся
компоненты. USB-флешка также может появиться среди физических дисков.
Сведения зависят от WMI, прошивки и прав доступа; не все устройства и поля
гарантированно доступны. MAC-адреса и серийные номера — чувствительные данные.

Начиная с версии 0.4.0 дополнительно определяются установленная память (с
резервным способом по модулям), код устройства SQM, код продукта Windows,
аппаратный UUID, тома и их свободное место, а также мониторы, устройства ввода
и принтеры, обнаруженные WMI. Поле даты установки читается из реестра с
резервным запросом к WMI. Подробности, источники и ограничения см. в
[формате отчёта](report-format.md). Файлы содержат идентификаторы устройства:
не публикуйте их без проверки.
